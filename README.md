This is a read-only mirror of https://skia.googlesource.com/skcms

Commits from source `main` branch are reflected in mirror `branch`.

`main` branch is used as start site and for GitHub workflows.

![skcms mirror status](https://raw.githubusercontent.com/gist/eustas/90b4ce8fce9d6ed3d8677adb38578678/raw/skcms_status.svg)

Tags with name like `YYYY_MM_DD` mark some commit of that day. Those are useful
for pinning, e.g. for Bazel Central Registry.
